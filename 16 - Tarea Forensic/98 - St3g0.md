### Descripción

Download this image and find the flag. [academy.flag.png](https://challenge-files.cylabacademy.net/library/8087998f70644cca47cf39fce5707a2b62b6d91d28f345ecc874238626c1cad2/academy.flag.png)
### Solución

1. Descargar `academy.flag.png` (661x181, RGBA).
2. Se revisaron los chunks del PNG (`tEXt`, `zTXt`, `iTXt`) y no había texto embebido, ni datos extra después de `IEND`.
3. Se probó esteganografía LSB (bit menos significativo) sobre los canales RGB, combinando los bits de cada píxel en orden R-G-B:

```python
   from PIL import Image
   im = Image.open('academy.flag.png').convert('RGBA')
   pixels = list(im.getdata())

   def extract_lsb(channel_indices):
       bits = []
       for p in pixels:
           for ci in channel_indices:
               bits.append(p[ci] & 1)
       chars = []
       for i in range(0, len(bits)-8, 8):
           byte = bits[i:i+8]
           val = 0
           for b in byte:
               val = (val<<1)|b
           chars.append(val)
       return bytes(chars)

   data = extract_lsb([0,1,2])  # canales R, G, B
   # b'academy{7h3r3_15_n0_5p00n_3e86461e}$t3g0\x00\x00...'
```

4. El mensaje aparece limpio desde el primer bit, terminado con relleno de ceros.

**Flag:** `academy{7h3r3_15_n0_5p00n_3e86461e}`

### Notas Adicionales

Clásico LSB-stego: cada píxel aporta 3 bits (uno por canal R, G, B), agrupados de a 8 para formar bytes ASCII. No había que tocar el canal alfa.
