### Descripción
  There is a nice program that you can talk to by using this command in a shell:
  $ nc wily-courier.picoctf.net 61480, but it doesn't speak English...

Pistas

### Solución
Ejecutar en la terminal:
```
nc wily-courier.picoctf.net 61480
```

Salio una lista de numeros y se pego en CyberChef usando la funcion from decimal
