### Descripción
What does asm2(0x4,0x29) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/970db6f9114bc04f46705c691cb4b3c3f2a9631904e972a84e9ce8d29714d3c8/test.S)
### Solución

1. Descargar el archivo `test.S` desde **Source** y examinarlo con `cat test.S`. El código del reto es:
    ```
    asm2:
        <+0>:  push   ebp
        <+1>:  mov    ebp,esp
        <+3>:  sub    esp,0x10
        <+6>:  mov    eax,DWORD PTR [ebp+0xc]
        <+9>:  mov    DWORD PTR [ebp-0x4],eax
        <+12>: mov    eax,DWORD PTR [ebp+0x8]
        <+15>: mov    DWORD PTR [ebp-0x8],eax
        <+18>: jmp    0x119c <asm2+31>
        <+20>: add    DWORD PTR [ebp-0x4],0x1
        <+24>: add    DWORD PTR [ebp-0x8],0x94
        <+31>: cmp    DWORD PTR [ebp-0x8],0x38f0
        <+38>: jle    0x1191 <asm2+20>
        <+40>: mov    eax,DWORD PTR [ebp-0x4]
        <+43>: leave
        <+44>: ret
    ```
    
2. Reconocer los argumentos en la pila (convención de llamadas x86 de 32 bits):
    
    - `[ebp+0x8]` corresponde al **primer argumento**, `0x4`.
    - `[ebp+0xc]` corresponde al **segundo argumento**, `0x29`.
    - Se guardan en variables locales: `[ebp-0x8] = 0x4` y `[ebp-0x4] = 0x29`.
3. Identificar el ciclo: el salto inicial `jmp` lleva directamente a la comparación en `<asm2+31>`. `jle` repite el bloque si el contenido de `[ebp-0x8]` es menor o igual que `0x38f0`.
    
    En cada vuelta se ejecutan dos operaciones:
    
    ```
    add DWORD PTR [ebp-0x4],0x1   ; contador / resultado += 1
    add DWORD PTR [ebp-0x8],0x94  ; variable de control += 148
    ```
    
    Los valores decimales relevantes son `0x94 = 148` y `0x38f0 = 14576`.
    
4. Calcular cuántas iteraciones se ejecutan. Partiendo de `x = 4`, el ciclo sigue mientras `x <= 14576` y aumenta `x` en `148`:
    
    ```
    x inicial = 4
    x tras 98 iteraciones = 4 + 98 × 148 = 14508 = 0x38ac
    x tras 99 iteraciones = 4 + 99 × 148 = 14656 = 0x3940
    ```
    
    Como `0x3940 > 0x38f0`, el ciclo termina después de **99 iteraciones**.
    
5. Calcular el retorno. La otra variable comienza en `0x29` (41 decimal) y aumenta en 1 por iteración:
    
    ```
    0x29 + 99 = 41 + 99 = 140 = 0x8c
    ```
    
    Finalmente, `mov eax,DWORD PTR [ebp-0x4]` coloca ese valor en `eax`, el registro utilizado para devolver el resultado.
    
6. Comprobarlo opcionalmente con Python:
    
    ```
    x = 0x4
    resultado = 0x29
    
    while x <= 0x38f0:
        resultado += 1
        x += 0x94
    
    print(hex(resultado))  # 0x8c
    ```

**Flag:** `0x8c`
### Notas Adicionales

Este reto utiliza un ciclo en ensamblador con `cmp` y `jle` (salto si es menor o igual, con comparación con signo). La instrucción `jmp` inicial evita ejecutar las sumas antes de comprobar la condición por primera vez. Es importante no confundir los argumentos: `0x4` controla el ciclo y `0x29` es el valor que se incrementa y devuelve.
